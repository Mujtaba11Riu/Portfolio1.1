Keylogger Detector Tool — Process Scanning, Hook Detection & Active Response

April 27, 2026 Syed Mujtaba Zaidi, Ammar Akhtar Butt & Ameer Hamza BS Cyber Security (Fall 2024) · Riphah International University

Keylogger Detector Tool is a desktop security application designed to detect and terminate malicious keyloggers on Windows systems in real time. Unlike conventional antivirus solutions that rely solely on hash databases, this tool combines signature‑based detection, keyword analysis, and behavioral indicators (keyboard hooks, suspicious DLL injection). It provides a lightweight, transparent, and actionable interface for students, security analysts, and privacy‑conscious users. The project is fully open source and includes a Fake Keylogger Simulator for safe ethical testing without risking real keystroke capture.

Key capabilities
Real‑time process enumeration (psutil)
Automatic threat flagging (25+ known names)
Global keyboard hook & DLL inspection (ctypes)
One‑click termination of suspicious processes
Built‑in Fake Keylogger Simulator for safe demos
Persistent threat logging (threat_log.txt)
Live search filter & whitelist management
Optional auto‑scan every 30 seconds

Detection Methodology — Three Layered Defense

The tool uses a multi‑stage heuristic approach. A running process is considered suspicious if it matches any of the following layers:

  • Layer 1 – Known executable names : Built‑in signature list of common keylogger filenames (e.g., keylogger.exe, spyagent.exe, hooker.exe, record.exe). Fast fingerprinting for commodity malware.
  • Layer 2 – Keyword scanning : Process name and full command line are scanned for red‑flag terms: “hook”, “keylog”, “record”, “capture”, “log”, “inject”. This catches renamed or obfuscated instances.

  • Layer 3 – Hook / DLL injection check : Using Windows API via ctypes, the tool inspects loaded modules and detects global keyboard hooks (SetWindowsHookEx). This behavioral layer is critical for zero‑day or fileless keyloggers that bypass static signatures.

If any layer triggers, the process is instantly displayed in the “DETECTED THREATS” table, and a timestamped entry is written to threat_log.txt.

Architecture & Technologies

The project is written in Python 3.10+ and follows a modular, event‑driven design to keep the GUI responsive during background scans.

  • GUI – Tkinter with a custom dark theme (GitHub‑style), real‑time table updates, start/stop controls, whitelist editor, and live search.
  • Process enumeration & management – psutil library: fetch all running processes (PID, name, exe path, command line) and terminate selected processes.
  • Low‑level hook detection – ctypes + user32.dll / kernel32.dll to inspect global hooks and suspicious DLLs.
  • Concurrency – Python threading module: background scan thread keeps the UI alive and supports the auto‑scan feature.
  • Persistence & logging – Plaintext log file (threat_log.txt) with timestamps, process names, PIDs, and detection reason.
  • Safe testing environment – keylogger_simulator.py mimics a keylogger’s behaviour (window, loop, dummy process name) but never captures real keystrokes.

Fake Keylogger Simulator – Ethical Testing

To demonstrate detection capabilities without any real risk, the repository includes a Fake Keylogger Simulator. Running this script creates a dummy process that behaves like a keylogger (name contains “keylog”, it may attempt to show a hidden‑style window). The detector immediately flags it as a threat, proving the tool’s effectiveness. Educators and students can use this simulator for live demonstrations, capture‑the‑flag exercises, or security training.

Quick demo workflow:
Terminal 1: python keylogger_simulator.py → starts dummy keylogger process.
Terminal 2: python keylogger_detector.py → click “START SCAN” → threat appears instantly.
Select threat → Click “Kill Selected” → process terminated.

Installation & Usage Guide

Prerequisites: Python 3.10 or newer (ensure pip is available).

# 1. Install required dependency (psutil)
pip install psutil

# 2. Clone or download the repository
git clone https://github.com/Mujtaba11Riu/Project-of-Software-Engineering-Keylogger-Detector-Tool.git
cd Project-of-Software-Engineering-Keylogger-Detector-Tool

# 3. Run the detector
python keylogger_detector.py

# (Optional) For safe demonstration, run the simulator in another terminal
python keylogger_simulator.py

Using the interface:
• Click “START SCAN” to manually scan all running processes.
• Enable “Auto-Scan (30s)” for continuous monitoring.
• Detected threats appear in the red‑highlighted table. Select any record and press “Kill Selected” to terminate the malicious process.
• Use “Search” to filter processes by name or PID.
• The “View File” button opens threat_log.txt containing full historical alerts.
• Add trusted executables to the whitelist to prevent false positives (e.g., system processes).

Building a standalone .exe (optional):
pip install pyinstaller
pyinstaller --onefile --windowed keylogger_detector.py

Why This Project Matters

Keyloggers remain one of the most prevalent threats for credential theft, corporate espionage, and privacy invasion. Most free anti‑keylogger tools lack transparency or rely on outdated signature databases. This project demonstrates how a combination of static (names, keywords) and dynamic (hook inspection) techniques can build an effective, low‑overhead detector. It also serves as an educational resource for students learning about Windows internals, process monitoring, and defensive programming.

Future Roadmap

  • Machine learning anomaly detection based on process behaviour (CPU spikes, keystroke frequency).
  • Network traffic analysis to detect remote keyloggers sending data to C2 servers.
  • Cloud‑based signature updates (automatic pull from a remote repository).
  • Cross‑platform support (Linux and macOS) using eBPF or similar low‑level hooks.
  • Export reports in JSON / CSV for security orchestration platforms.
